# 💣 赛博扫雷 - Cyber Minesweeper

一个酷炫的移动端扫雷游戏，采用赛博朋克风格设计，具有丰富的视觉效果和流畅的触摸交互。

## ✨ 特性

### 🎨 视觉效果
- **霓虹灯标题** - 闪烁的赛博朋克风格标题
- **动态渐变背景** - 持续变化的彩色渐变动画
- **粒子背景** - Canvas 绘制的动态粒子连线效果
- **毛玻璃效果** - 半透明背景模糊（backdrop-filter）
- **翻转动画** - 3D 翻转卡片揭示效果
- **爆炸动画** - 踩到地雷时的爆炸特效
- **烟花效果** - 胜利时的庆祝烟花
- **旗帜挥动** - 插旗时的动画效果
- **响应式设计** - 完美适配各种屏幕尺寸

### 📱 移动端优化
- **触摸友好** - 优化的触摸目标大小
- **长按插旗** - 长按 0.5 秒插旗，短按揭示方块
- **触觉反馈** - 支持震动反馈（兼容设备）
- **防止缩放** - 禁用双击缩放，优化游戏体验
- **禁用选择** - 防止误触导致的文本选择
- **viewport 优化** - 适配移动端视口

### 🎮 游戏功能
- **三种难度**：
  - 简单：8×8，10 个地雷
  - 中等：10×10，20 个地雷
  - 困难：12×12，30 个地雷
- **计时器** - 记录游戏时间
- **旗帜计数** - 实时显示已插旗数量
- **智能揭示** - 点击空白区域自动展开
- **游戏统计** - 显示地雷数、时间和旗帜数

### 🎯 交互方式

#### 移动端
- **短按/轻触** - 揭示方块
- **长按（0.5秒）** - 插/拔旗帜

#### 桌面端
- **左键点击** - 揭示方块
- **右键点击** - 插/拔旗帜

## 🚀 使用方法

直接在浏览器中打开 `index.html` 文件即可开始游戏。

```bash
# 使用 Python 启动本地服务器
python -m http.server 8000

# 或使用 Node.js
npx serve
```

然后访问 `http://localhost:8000`

## 🎨 技术特色

- **纯原生开发** - 不依赖任何框架，使用原生 HTML/CSS/JavaScript
- **Canvas 动画** - 粒子系统和烟花效果
- **CSS3 动画** - 丰富的过渡和关键帧动画
- **触摸事件** - 完整的触摸事件处理
- **响应式布局** - Flexbox 和 Grid 布局
