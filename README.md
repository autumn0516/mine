# 💣 赛博扫雷 2.0 - Cyber Minesweeper

一个超酷炫的移动端扫雷游戏，采用赛博朋克风格设计，支持单人模式和多人联机对战，配备五种强力技能系统！

## ✨ 核心特性

### 🎮 双模式游戏

#### 单人模式
- 经典扫雷玩法
- 三种难度选择（简单/中等/困难）
- 实时计时系统
- 最佳成绩记录

#### 联机对战模式 ⭐ 新功能
- 最多 4 人实时对战
- WebSocket 实时通信
- 房间创建和加入系统
- 实时排行榜
- 积分竞技系统

### 🎯 技能系统 ⭐ 新功能

每个玩家拥有 5 种强力技能，合理使用技能是制胜关键！

| 技能 | 图标 | 次数 | 效果描述 |
|-----|-----|-----|---------|
| **冰冻** | ❄️ | 2 | 冰冻所有对手 3 秒，阻止他们操作 |
| **透视** | 👁️ | 2 | 查看 3×3 区域内的所有方块内容 |
| **炸弹** | 💥 | 1 | 炸开 5×5 区域，直接揭示所有安全方块 |
| **护盾** | 🛡️ | 1 | 下次踩到地雷时免受伤害和扣分 |
| **交换** | 🔄 | 1 | 交换两个未揭示方块的位置 |

### 🎨 视觉效果

- **霓虹灯标题** - 闪烁的赛博朋克风格标题
- **动态渐变背景** - 持续变化的彩色渐变动画
- **粒子背景系统** - Canvas 绘制的动态粒子连线效果
- **毛玻璃效果** - 半透明背景模糊（backdrop-filter）
- **3D 翻转动画** - 卡片揭示的 3D 翻转效果
- **技能特效动画** - 每个技能都有独特的视觉特效
  - 冰冻：蓝色脉冲效果
  - 透视：金色发光边框
  - 炸弹：橙色爆炸扩散
  - 护盾：绿色保护光环
- **烟花庆祝** - 胜利时的华丽烟花效果

### 📱 移动端优化

- **触摸友好** - 优化的触摸目标大小
- **长按插旗** - 长按 0.5 秒插旗，短按揭示方块
- **触觉反馈** - 支持震动反馈（兼容设备）
- **防止误触** - 禁用双击缩放和文本选择
- **完美适配** - 响应式设计，适配所有屏幕尺寸
- **流畅体验** - 60fps 动画和即时响应

### 🏆 对战机制

**积分规则：**
- 揭示数字方块：数字 × 2 分
- 揭示空白方块：5 分
- 踩到地雷：-50 分（有护盾时不扣分）
- 技能加成：使用技能获得的方块也计分

**胜利条件：**
- 当所有安全方块被揭示完毕时，游戏结束
- 得分最高的玩家获胜
- 实时显示排名和分数

## 🎯 游戏玩法

### 单人模式

1. 选择"单人模式"
2. 选择难度等级
3. 点击方块揭示内容
4. 长按方块插旗标记
5. 揭示所有非地雷方块即可获胜

### 联机对战模式

#### 创建房间
1. 选择"联机对战"
2. 输入你的昵称
3. 点击"创建房间"
4. 分享房间 ID 给好友
5. 等待玩家加入后点击"开始游戏"

#### 加入房间
1. 选择"联机对战"
2. 输入你的昵称
3. 点击"加入房间"
4. 输入房间 ID
5. 等待房主开始游戏

#### 对战技巧
- 优先揭示高价值区域（数字大的地方）
- 合理使用技能打乱对手节奏
- 使用冰冻技能在关键时刻阻止对手
- 透视技能帮你找到安全区域
- 炸弹技能可以快速获得大量分数
- 护盾技能让你敢于冒险
